Building the Agentic Software Delivery platform — a system that turns real software requirements into controlled, evidence-backed, verified changes, with human approval required for anything beyond small, reversible, low-risk work. Direction: architecture, delivery, and technical leadership for AI-assisted engineering.

What This Platform Actually Does (evidence, not claims)

  • LLM tool-calling agent loop — investigates a real repository and proposes source changes using Claude's tool-use API. Runtime verified
  • Safe write boundary — propose → approve → apply, with approval cryptographically bound to the exact content approved; a model can never approve its own change. Unit tested + runtime verified
  • Risk-gated bounded autonomy — small, low-risk, reversible changes execute automatically with real compile/test/deploy verification; everything else requires explicit Owner Authorization. Production verified
  • Local semantic RAG + MCP adapter — hybrid retrieval (semantic search finds candidates, tools verify before any claim is asserted). Runtime verified
  • Durable event ledger — real Postgres-backed, append-only, write-through capture of Workbench runs and Claude Code development activity, with outage-safe local spooling and idempotent sync. Production verified
  • Production verification, not self-reported success — every deploy is independently confirmed against the real live application, not trusted from a deploy tool's own status.
