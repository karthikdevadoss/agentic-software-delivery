How this stays honest

The AI only proposes. It extracts the requirements from your text, and it may pick capabilities only from a shortlist that code built from a verified registry. Then code decides what you see: any capability the model names that is not on that shortlist is dropped; a "demonstrated" with no valid evidence becomes "not yet demonstrated"; a status can never exceed the verification level recorded for the capability; every link comes from the registry, never from model text; and every reason is scanned for claims the evidence cannot carry (employer work, scale numbers, certifications, contact details) and withheld on a hit.

Truth over impressiveness: a false "demonstrated" is a worse outcome here than a missing feature.
