What is indexed

A small, curated, real slice of this repository: its own Java source and its architecture documents. Retrieval is deterministic — the same question returns the same evidence — and when nothing relevant is indexed it says so rather than guessing.

Portfolio scope, stated plainly: a curated corpus, not the whole repository, and not an enterprise-scale index. "How this works" below names exactly what is in it and why.

How this works

Retrieval
Local embedding model (fastembed, no API key/cost) + cosine similarity over pre-computed vectors — a real, deterministic function, not a model guessing.
Corpus
~28 curated files: core Customer-app Java source/tests for the topics below, plus this project's own real interview-scenario write-ups. Explicitly curated (a code-reviewed list), never the whole repository, never anything private.
Security boundary
Structural, not a promise a model might ignore: there is no code path from any query to any file outside that curated list — no read/write/execute tool is reachable from this page at all.
Evidence quality
Real cosine similarity scores shown per result, using the same confidence threshold (0.45) already used elsewhere in this codebase's own internal RAG pipeline.
