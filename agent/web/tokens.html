Token X-ray

Same answers. 4.5x the tokens. 4.2x the cost.

I gave an AI model six everyday tasks twice: once the wrong way (a vague start, a huge paste, one never-ending chat, the biggest model for a small job) and once the right way. The final answers were the same. The wrong way used 56,188 tokens. The right way used 12,601.

Honest limits: 6 tasks, Claude models only, median of 3 runs, measured on 21 Oct 2026. Cost uses Anthropic list prices without caching. Other AI models were not measured, and their numbers will differ.

Why it happens

What this shows, and what it does not

  • ShownUsing AI the wrong way costs many more tokens for the same answer. This test shows it on six tasks.
  • Partly shownTokens are becoming a real cost line in software work, and "minimal AI" is a useful habit. But minimal means no waste, not "as few tokens as possible": on hard tasks, more tokens can still give a better answer.
  • Not claimedThat only the token count matters. The task must be solved and checked first.

The rule I work by

Solved. Checked. Then the fewest tokens.

On this site: a Workbench click runs plain code and makes no model call ($0.00). Ask the Codebase answers from local search over the repository, with no model call. The model is used only where code cannot do the job.

How it was measured

  • Claude Code command line in print mode with JSON output, which reports the real token use and cost of every call. A minimal system prompt, all tools off.
  • Claude Sonnet 5.5 for five tasks. The formula task compared Opus 5.5 (maximum thinking) with Haiku 5.5 (low effort).
  • Every task done the wrong way and the right way, 3 runs each, median shown. 117 model calls in total.
  • Cost = Anthropic list price without caching, so caching does not hide the effect. With caching, money changes but the tokens processed do not.
  • Each message carries a small fixed overhead (the system prompt), which makes the multiple smaller for tiny tasks.
  • The raw call logs, the analysis script and the chart script are in the repository: docs/evidence/token-xray-2026-10-21.
