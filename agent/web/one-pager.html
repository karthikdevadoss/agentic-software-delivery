What this platform is

An agentic delivery platform I built and operate. It takes a written requirement, changes a real Java 21 / Spring Boot application, verifies the change and records what it cost. You can run it yourself from the pages in the navigation above.

Who decides what runs

A deterministic policy decides, not the model. That gives two paths, and both are true at once:

  • A request inside a narrow, pre-declared band is implemented, verified and deployed to the demo application without a person. There is no approval event on that path, and no model call on it either. That band is a fixed catalogue of operations written in advance, matched by exact text: it is not a general-purpose agent and it cannot make a change the catalogue does not already name.
  • Anything outside that band waits for a person. The approval is bound by hash to the exact file and content approved, and the approve step is not something the model can call.

The Incident Triage Lab always stops at a human approval, whatever the fix looks like.

What it will not do

  • It does not approve its own writes, and no path lets it.
  • It does not route between model providers, and it holds no managed vector search; those remain future work.
  • It does not send anything on my behalf. Where a job application is involved, the drafting stops before sending and I apply myself.

Three things you can run here

  • Workbench — submit a written requirement and watch it change, verify and deploy the demo application.
  • Ask the Codebase — ask a question and get the answer out of the real repository, with the files it read.
  • Triage — work a contained defect to the human approval step, which is where it stops.
