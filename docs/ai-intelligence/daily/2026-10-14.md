## 8. One experiment worth running

Building on the "agent falsely denies prior work happened" bug above: the next time a long AI-coding-agent session auto-compacts (summarizes itself), don't just keep working — immediately ask it a specific, checkable question about something it did earlier in that same conversation (a file it changed, a decision it made, a number it reported), and check the answer against the real record (the actual file, the git history). This directly tests whether the session's memory survived the compaction intact, which is exactly the kind of gap that's invisible unless you deliberately check for it instead of trusting the tool's confident-sounding continuation.
