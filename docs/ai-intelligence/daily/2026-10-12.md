## 2. Model/Tool Recommendations Today

**If you run unattended, multi-session coding-agent automation under a "bypass all permissions" setting, don't assume it is actually hands-off.**
A real, measured report shows the bypass mode still occasionally stops to ask for confirmation — roughly once per 1,300 commands in one person's setup — and some of those pauses happen inside background sub-tasks where nobody sees the prompt, silently stalling that piece of work. Worth checking your own automation for this before trusting a long unattended run to finish on its own.

**If you manually trigger a coding assistant's "compress the conversation" feature, keep testing before relying on it — a new theory suggests the bug may be older and more persistent than first thought.**
Yesterday's reported bug (a broken message right after manual compaction) was reproduced across multiple past software versions this cycle, suggesting it isn't a one-time regression that will simply be patched away soon. Letting the automatic version run, rather than triggering it by hand, remains the safer path for now.

**If you combine a model's highest reasoning-effort setting with heavy multi-agent parallelism, know that neither major coding-assistant platform currently warns you before you burn through your usage allowance.**
This has now happened on both Anthropic's and OpenAI's coding tools within about a day of each other. Treat "maximum effort plus heavy parallelism" as something to test cautiously and watch closely, not as a safe default to turn on and walk away from.

## 8. One Experiment Worth Running

The next time you ask any AI coding assistant to confirm it fully updated documentation, comments, or other related text after changing how something works, don't just accept its own "done" checkbox. Instead, independently compare every file the change could plausibly have touched against how it looked before the change — not just the files the assistant says it touched — and specifically look for other places that describe the same fact in different words (a help page, an example, a settings screen, a date stamp) that a simple text search for "the old phrase" would miss. Today's finding (an assistant's own documentation check missed 4 of 7 outdated spots because it searched for one specific old phrase instead of comparing full files) shows exactly the kind of gap this catches.
