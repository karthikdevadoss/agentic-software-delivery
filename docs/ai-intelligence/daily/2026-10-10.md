## 8. One experiment worth running

**Before trusting that a tool's bug-fix release notes cover the whole problem, test it yourself on your own setup — including a scenario the notes don't explicitly mention.**
The pattern today (a fixed terminal crash followed almost immediately by a different terminal failure in the same window; a suppressed-error bug recurring in a second, unrelated command type after showing up once the day before) suggests fixes described in changelogs are often narrower in practice than they sound. The useful habit: when a tool you rely on ships a fix for a specific bug, re-run the exact scenario the fix targeted on your own machine before trusting it's resolved — and also try one related but different scenario in the same part of the program, since that's exactly where today's gaps showed up.
