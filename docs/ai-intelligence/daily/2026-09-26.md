## 3. New Advanced AI Workflow Techniques

No new named positive workflow pattern surfaced this cycle. Two cautionary lessons stand out:

**Verify what an AI agent actually did against the real record, never against the agent's own account of what it did.** A documented case this week showed an agent's own restated summary of "what the user asked" was flatly wrong, and the agent kept insisting on the wrong version even after it was questioned. Any process that checks an agent's work by reading its own summary, rather than the actual conversation log or actual file changes, is vulnerable to exactly this.

**Put a hard cap on how much infrastructure an unattended AI agent is allowed to create for a given task.** A report this week described an agent building far more scaffolding (multiple parallel workspaces, several sub-agents, unrequested branches) than a simple task called for, without finishing the actual task. Rather than trusting the model's own judgment on "how much setup this needs," an explicit limit in the task instructions or the surrounding tooling is a more reliable guardrail.
