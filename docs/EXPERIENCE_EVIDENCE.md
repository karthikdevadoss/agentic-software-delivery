# Experience Evidence

Maps real, currently-implemented capabilities in this repository to
runnable evidence — for resume claims and interview answers that can be
demonstrated live, not just described. Only capabilities that actually
exist today are listed here; see docs/ROADMAP.md for future-only items,
which must never be presented as implemented.

Update this file when a capability's implementation or verification
status materially changes — don't let it drift from repository reality.

## What is explicitly NOT here (and should not be claimed)
Self-correction loop, multi-agent architecture, deployment pipeline,
production customer pilot, token/cost telemetry, enterprise-scale RAG
benchmark, MCP write/build/deploy tool exposure. These are real gaps —
see the Dashboard's Known Limitations panel and docs/PROJECT_STATE.json's
`missing_capabilities` for the current, authoritative list.
