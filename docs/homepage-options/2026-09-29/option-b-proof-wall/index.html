Agentic AI — built and running

Live

Human approval the model cannot bypass

Approval is bound by hash to the exact path and content approved; changing either after approval is rejected. The approve and reject functions are absent from the model's tool schema, so it has no code path to approve its own change. Both properties are asserted by tests, not by a prompt.

write_tools.py the tests running

Live

Durable agent workflow that survives a crash mid-run

LangGraph state machine with checkpoints in Postgres, a human interrupt, and idempotent side effects. A crash drill killed a real child process after its git commit and before the checkpoint; a fresh process recognised its own commit and refused to write twice — 22 of 22 assertions in one run. In production it survived a real container restart while waiting for approval.

durable_workflow.py the crash drill

Retrieval with a labelled evaluation that blocks CI

Recall@3 0.83, Recall@5 0.92, MRR 0.83 across twelve labelled cases, plus routing accuracy 1.0. Small numbers from a real set, re-run on every build; if they regress, the build fails.

One model boundary, with an off switch

Retrieval over my own recorded engineering knowledge. Below a grounding threshold, code refuses before the model is called. No corpus text is in the public repository — it is built separately and delivered at deploy time.

Every model call metered in a durable ledger

A write-through event ledger in Postgres that spools locally when the remote is unreachable, so a telemetry outage degrades instead of losing rows. Real token counts per call.
