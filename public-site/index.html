Agentic Software Delivery — Public Overview

An AI agent that safely proposes and verifies real code changes — with a human approval boundary the agent structurally cannot bypass.

Overview · Dashboard · Sessions

What is this?

This system takes a business requirement, investigates a real Spring Boot codebase using retrieval-augmented search, proposes a specific code change, and only applies it after a human explicitly approves — a boundary enforced outside the model's own tool access, not just by policy. Once approved, the change is compiled and tested with real, controlled tools before being reported as verified.

What you can see here

Dashboard — real architecture, capability, and verification evidence for this system: what's implemented, what's tested, what's still a known gap. No fabricated status — unavailable data is always labeled, never invented.

Sessions — how human and AI time/tokens were actually used to produce this system, including a scored (and honestly-coverage-labeled) effectiveness assessment of each build session.

What's not here yet

The interactive Control Plane (submit a requirement, click Approve/Reject, watch a live build/test run) is not exposed publicly in this release — it currently requires the operator to run it locally, since anonymous visitors do not have production release authority and the current architecture doesn't yet have a safe public write boundary. The Dashboard and Sessions pages here are a real snapshot published from that local system, not a live connection.

The actual Spring Boot business application (the target the agent modifies) is a separate system from this control/evidence surface — see the Dashboard for its current public deployment status.
